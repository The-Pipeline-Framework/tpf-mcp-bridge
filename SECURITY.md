# Security Policy

This repository owns the public, read-only TPF Author Knowledge MCP and its Cloudflare publication path.

Report vulnerabilities privately to [security@pipelineframework.org](mailto:security@pipelineframework.org) or [team@pipelineframework.org](mailto:team@pipelineframework.org). Do not open a public issue for a vulnerability.

Please include reproduction steps, affected endpoints or versions, impact, and any known mitigation. Reports are normally acknowledged within 48 hours, with an initial response within five business days.

The public service is intentionally anonymous and stateless. It must not expose maintainer-only source, raw Repowise exports, storage credentials, infrastructure details, arbitrary repository reads, write operations, sessions, or code execution.
